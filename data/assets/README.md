# 模板图片目录

这里存放“丝绸之路”自动点击器需要的按钮截图，由 tools/grab_template.py 生成。

## 生成方法

1. 打开游戏，停在会显示这些按钮的界面
2. 运行：python tools/grab_template.py --preset
3. 按提示依次框选每个按钮，自动保存
